## Findings

1. **[P2] 11-long-context-is-a-memory-product.md §11.5 (Layer one: the money) — compaction-turn arithmetic contradicts the multipliers it invokes.** Text: "Work it yourself with chapter 6's multipliers (write 1.25×, read 0.1× on 5-minute caches, mid-2026): a session holding 150K cached tokens re-reads it each turn at ~15K-token-equivalents. Derivation: on the very providers whose multipliers are named (Anthropic 5-min, OpenAI GPT-5.6+ — both 1.25× writes per prompt-caching-provider-semantics.md), a post-compaction re-prefill is a fresh cache *write*: 30K × 1.25 = 37.5K-equivalents = **2.5×** the pre-compaction 15K, not 2×. The 2× figure holds only where writes are uncharged (pre-5.6 OpenAI, Gemini implicit). Conflict: internal — the sentence instructs the reader to use the write multiplier and then bills the write at 1.0×; Checkpoint Q5 bakes the same framing in ("one full-price re-prefill"). Note research/context-compaction-tradeoffs.md makes the identical 1× simplification, but without first invoking the 1.25× multiplier, so the contradiction is the chapter's. Smallest fix: "(up to 2.5× that turn with a 1.25× write premium; 2× where writes are free)" — or drop "(write 1.25×, read 0.1×…)" from the invocation. The steady-state conclusion (3K-equiv, 5× cheaper) is unaffected.

2. **[P2] 06-paging-the-brain.md §6.3 and "Where the picture stops" — the 20–26% kernel tax is universalized beyond its digest.** Text: "the paged attention kernel is 20–26% slower per call… — the ledger lookup is work, every attention pass, **forever**" and "every attention pass in every decode step walks the block table — the 20–26% kernel tax, **paid forever**." Smallest fix: attach the era hedge to the kernel bullet ("on the paper's 2023 measurements") or soften "forever" to "for as long as the gather runs through the block table".

3. **[P2] 11-long-context-is-a-memory-product.md "Prove it" — the expected attention-crossover length is model-scale-dependent, not "past 100K".** Text: "on any endpoint you control, measure TTFT at 8K, 32K, 128K, 256K input and plot it: watch the quadratic term take over from the linear one **somewhere past 100K**."
